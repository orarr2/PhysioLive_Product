# Hip corpus

Hip-focused evidence used by the coach for glute bridge, straight leg
raise, and any exercise that queries the hip family:

- **Gluteus medius and knee tracking.** Weak hip abductor is upstream
  of dynamic knee valgus and iliotibial band syndrome.
- **Glute bridge.** Terminal hip extension target with neutral pelvis;
  common cue against lumbar hyperextension.
- **Straight leg raise.** Quadriceps set at ~30 deg hip flexion with a
  locked knee; used early post-op for knee rehab.
