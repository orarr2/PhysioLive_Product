# Reference videos

Place professional demonstration videos here, one subfolder per exercise:

```
reference_videos/
  squat/
    prophysio_01.mp4
    prophysio_02.mp4
    ...
```

Videos are used offline to build angle signatures. The raw mp4 files stay
gitignored (see project `.gitignore`); only the derived JSON signatures
under `data/reference_signatures/` are checked in.

Recommended source for M2 (Squat): 3-5 clips from ProPhysioClinic on
YouTube showing correct squat form, side and front views.
