# Reference videos

Place professional demonstration videos here, one subfolder per exercise:

```
reference_videos/
  squat/
    demo_01.mp4
    demo_02.mp4
    ...
```

Videos are used offline to build angle signatures. The raw mp4 files
stay gitignored (see project `.gitignore`); only the derived JSON
signatures under `data/reference_signatures/` are checked in.

Recommended: 3-5 clips per exercise from a qualified physiotherapist
performing the exercise correctly, filmed from both side and front
views.
