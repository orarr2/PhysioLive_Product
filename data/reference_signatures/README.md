# Reference signatures

This folder holds per-exercise "ground-truth" angle signatures built from
professional demonstration videos. Each signature is a JSON file with the
angle time-series statistics (min, max, mean, std, tempo, ROM utilization)
that the live pipeline compares each rep against.

Structure:
```
reference_signatures/
  squat/
    signature_001.json     one signature per demo video
    signature_002.json
    ...
```

Signatures are generated by `src/app/tools/build_signature.py` (added in
M2) from mp4 files placed under `data/reference_videos/<exercise>/`. The
raw videos stay gitignored; only the derived signatures are checked in.
